# French Tutorial Video Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Produce `tutorial-video-fr/` — a French rendering of the existing 60-second tutorial video that is pixel-identical to the English original in layout, timing, motion, and assets, differing only in language.

**Architecture:** The five screencast beats each embed a *copy* of a portal page's markup. A feasibility probe (run 2026-08-18) confirmed **100% of that embedded markup is already covered by the existing `i18n/*.fr.json` catalogs — zero gaps across all 315 unique strings.** So the French beats are generated by pointing the existing `tools/build-i18n.js` at the composition files rather than by hand-translating them. Only the ~18 *video-specific* strings (11 subtitles, 4 intro, 3 outro) are new, and they live in a new `i18n/video.fr.json`. A thin driver script (`tools/build-video-i18n.js`) composes the existing generator with one added pass for subtitle literals.

**Tech Stack:** Node 20+ (`node:test`, no new runtime deps), existing `tools/build-i18n.js` (exports `translateHtml`, `buildAll`, `loadCatalog`, `unescapeHtml`), HyperFrames CLI (`npx hyperframes check|snapshot|preview|render`), GSAP 3.14.2 / 3.12.2 (CDN, unchanged), Playwright (already a devDependency) for layout measurement.

## Global Constraints

- **Identity rule:** `tutorial-video-fr/` must differ from `tutorial-video/` in **language only**. Timing, `data-start`, `data-duration`, `data-track-index`, z-index, cursor coordinates, easing, asset paths, and all `data-hf-id` attributes are preserved byte-for-byte.
- **Do not modify `tutorial-video/`.** The English project is the source of truth and stays untouched. Every French artifact is generated into a new sibling directory.
- Render target: **1920×1080, 60s total**, matching `tutorial-video/index.html` root `data-duration="60"`.
- Composition IDs stay `main`, `beat-00`…`beat-06` (HyperFrames requires the host slot's `data-composition-id` to equal the inner template's; renaming them breaks rendering).
- Formal French register (`vous`/`votre`) throughout, per `i18n/glossary.md`.
- Terminology must come from `i18n/common.fr.json` and `i18n/glossary.md` — never re-invent a term already fixed there (e.g. *Labour Market Portal* → *Portail du Marché du Travail*).
- Proper nouns in `i18n/do-not-translate.json` (46 entries) stay unchanged, including `iCUBEFARM EG SL`, `Malabo`, `Bata`, and demo person names.
- Generated files carry a `<!-- GENERATED FILE - DO NOT EDIT DIRECTLY -->` header, consistent with `/fr` and `/es`.
- Assets (`bgm-icubefarm.mp3`, `bgm-african-classical.mp3`, `corporate_writing_grayscale.jpg`) are **copied, not re-encoded**.
- French runs 15–25% longer than English. Two elements use `white-space: nowrap` and **will** overflow — see Task 5. Never fix overflow by changing layout geometry; fix by shortening copy or reducing font-size within the documented fallback chain.

**3. Orphan files — do NOT port them.** `compositions/beat-02-verify.html` and `compositions/beat-03-skills.html` exist on disk but are **not referenced** by `index.html`. They are superseded drafts. Porting them wastes effort and creates duplicate-id render hazards.

**4. Sub-comp `data-duration` disagrees with host clip duration and that is fine.** e.g. `beat-01` declares `data-duration="19"` internally while the host clip allots 10s. **The host wins for render.** Preserve both values exactly as-is; do not "fix" the discrepancy — doing so would change output timing and violate the identity rule.

**5. `beat-06-outro.html` declares `data-duration="6"` while its host clip allots 5.** Same rule: preserve verbatim.

**6. There is a literal two-character `\n` sequence in each beat right after `<body>`** (`<body>\n<div data-hf-id=…`). It is an existing English artifact. **Preserve it.** Do not translate it, do not clean it up.

**7. Subtitles are NOT in `/* i18n:STR:start */` blocks.** The existing `translateStrBlock` will not reach them. They appear only as `.set("#subtitle-container", { textContent: "…" })` — 11 occurrences total, all subtitles, none in the embedded portal JS. Task 3 adds a dedicated pass for exactly this pattern.

**8. Two `white-space: nowrap` overflow risks in `beat-00-intro.html`:**
- `.headline > div { white-space: nowrap }` at `font-size: 96px; font-weight: 800`
- `.title { white-space: nowrap }` at `font-size: 30px; letter-spacing: 0.075em`

Both sit in a `1064px` container (`.text-container`). The English `.title` string is 43 chars; the natural French rendering is ~68 chars (≈1.6×). **This will overflow.** Task 5 measures and remediates.

Create `tools/lib/translate-subtitles.js`:

```js
'use strict';

/**
 * Translates GSAP subtitle literals of the form:
 *   .set("#subtitle-container", { textContent: "..." })
 *
 * Only the string literal following `textContent:` is touched. All surrounding
 * JavaScript is left byte-identical — this never parses or rewrites arbitrary code.
 */

const SUBTITLE_RE = /(textContent:\s*")((?:[^"\\]|\\.)*)(")/g;

function unescapeJs(s) {
  return s.replace(/\\(["\\/bfnrt])/g, (_, c) => {
    const map = { b: '\b', f: '\f', n: '\n', r: '\r', t: '\t' };
    return map[c] !== undefined ? map[c] : c;
  });
}

function escapeJs(s) {
  return s.replace(/\\/g, '\\\\').replace(/"/g, '\\"');
}

/**
 * @param {string} html
 * @param {Record<string,string>} catalog
 * @param {{strict?: boolean}} [opts]
 * @returns {{html: string, translated: number, missing: string[]}}
 */
function translateSubtitles(html, catalog, opts = {}) {
  const missing = [];
  let translated = 0;

  const out = html.replace(SUBTITLE_RE, (match, open, body, close) => {
    const key = unescapeJs(body);
    if (Object.prototype.hasOwnProperty.call(catalog, key)) {
      translated += 1;
      return `${open}${escapeJs(catalog[key])}${close}`;
    }
    missing.push(key);
    return match;
  });

  if (opts.strict && missing.length > 0) {
    throw new Error(
      `Untranslated subtitle(s):\n  - ${missing.join('\n  - ')}`
    );
  }

  return { html: out, translated, missing };
}

module.exports = { translateSubtitles };
```

```js
#!/usr/bin/env node
'use strict';

/**
 * tools/build-video-i18n.js
 *
 * Generates tutorial-video-<locale>/ from tutorial-video/.
 * Language differs; timing, motion, ids, and assets do not.
 */

const fs = require('node:fs');
const path = require('node:path');
const { translateHtml, loadCatalog, loadDoNotTranslate } = require('./build-i18n.js');
const { translateSubtitles } = require('./lib/translate-subtitles.js');

/** Composition file -> page catalog basename. `null` = artwork, uses video catalog only. */
const BEAT_CATALOG_MAP = {
  'beat-00-intro.html': null,
  'beat-01-dashboard.html': 'index',
  'beat-02-verification.html': 'entities',
  'beat-03-skill-gap.html': 'skill-gap',
  'beat-04-reports.html': 'general-report',
  'beat-05-audit.html': 'activity-logs',
  'beat-06-outro.html': null
};

const ASSETS = ['bgm-icubefarm.mp3', 'bgm-african-classical.mp3', 'corporate_writing_grayscale.jpg'];

const GENERATED_HEADER = '<!-- GENERATED FILE - DO NOT EDIT DIRECTLY. Source: tutorial-video/ -->\n';

function buildVideoLocale({ srcDir, outDir, i18nDir, locale }) {
  const common = loadCatalog(path.join(i18nDir, `common.${locale}.json`));
  const video = loadCatalog(path.join(i18nDir, `video.${locale}.json`));
  const dnt = loadDoNotTranslate(path.join(i18nDir, 'do-not-translate.json'));

  fs.rmSync(outDir, { recursive: true, force: true });
  fs.mkdirSync(path.join(outDir, 'compositions'), { recursive: true });
  fs.mkdirSync(path.join(outDir, 'assets'), { recursive: true });

  const generatedFiles = [];

  // Host composition: no portal markup, but carries <html lang> and the title.
  const hostSrc = fs.readFileSync(path.join(srcDir, 'index.html'), 'utf8');
  const hostOut = translateHtml(hostSrc, {
    catalog: { ...common, ...video },
    doNotTranslate: dnt,
    locale,
    rewriteToggle: false
  });
  fs.writeFileSync(path.join(outDir, 'index.html'), GENERATED_HEADER + hostOut, 'utf8');
  generatedFiles.push('index.html');

  for (const [file, pageName] of Object.entries(BEAT_CATALOG_MAP)) {
    const src = fs.readFileSync(path.join(srcDir, 'compositions', file), 'utf8');
    const page = pageName ? loadCatalog(path.join(i18nDir, `${pageName}.${locale}.json`)) : {};
    const catalog = { ...common, ...page, ...video };

    let out = translateHtml(src, {
      catalog,
      doNotTranslate: dnt,
      locale,
      rewriteToggle: false
    });

    // Subtitles live outside i18n:STR blocks; strict so a gap fails the build.
    out = translateSubtitles(out, video, { strict: true }).html;

    fs.writeFileSync(path.join(outDir, 'compositions', file), GENERATED_HEADER + out, 'utf8');
    generatedFiles.push(`compositions/${file}`);
  }

  const copiedAssets = [];
  for (const a of ASSETS) {
    const from = path.join(srcDir, 'assets', a);
    if (!fs.existsSync(from)) continue;
    fs.copyFileSync(from, path.join(outDir, 'assets', a));
    copiedAssets.push(a);
  }

  return { generatedFiles, copiedAssets };
}

if (require.main === module) {
  const locale = process.argv[2];
  if (!locale) {
    console.error('Usage: node tools/build-video-i18n.js <locale>   e.g. fr');
    process.exit(1);
  }
  const root = process.cwd();
  const result = buildVideoLocale({
    srcDir: path.join(root, 'tutorial-video'),
    outDir: path.join(root, `tutorial-video-${locale}`),
    i18nDir: path.join(root, 'i18n'),
    locale
  });
  console.log(
    `✓ tutorial-video-${locale}: ${result.generatedFiles.length} compositions, ` +
    `${result.copiedAssets.length} assets copied.`
  );
}

module.exports = { buildVideoLocale, BEAT_CATALOG_MAP };
```
